Solmar Heat — an original open-world crime game in the spirit of GTA 6. Explore the sun-soaked coastal city of Solmar on foot and by car, steal cars, outrun the Solmar PD, and run story missions for fixer Lena Torres to pay off your debt to King Bell. Built with three.js; static files only, zero network requests, keyboard + mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Drive with WASD, steer with the mouse, E to enter/exit a car, F to punch, click to shoot, Shift to sprint, Space to jump, M for the mission list, P to pause.
